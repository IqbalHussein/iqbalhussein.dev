# iqbalhussein.dev

Personal portfolio site, live at [iqbalhussein.dev](https://iqbalhussein.dev).

Plain static HTML and CSS, generated by `build.py`.

## Editing

All content (projects, descriptions, links, pictograms) lives in `build.py`. Edit it, then rebuild:

```bash
python3 build.py
```

This writes `index.html`, `work.html`, `about.html`, `contact.html` and `work/<project>.html`. Styles are in `styles.css`.

## Deploying

Hosted on Vercel with no build step; the repository root is served as is.
