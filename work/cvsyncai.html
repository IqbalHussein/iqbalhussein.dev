CVSyncAI

CVSyncAI pulls the skills out of job postings, from a vocabulary of about 250 across software, finance, healthcare, law and more, and ranks the postings against a resume. The score blends skill overlap with semantic similarity; the weighting was tuned on a hand-labelled benchmark against keyword, TF-IDF and embedding-only baselines.

Source on GitHub
Built with
Python, spaCy, sentence-transformers, scikit-learn, Streamlit
Status
Source code

What it does

  • Shows matched and missing skills, with the line of the posting that mentions each one.
  • Suggests resources for the missing skills.
  • Drafts a cover letter for a chosen posting and exports it as a PDF.
  • Runs from the command line or as a Streamlit web app.
