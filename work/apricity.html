Apricity

Type a look such as “cold, desaturated noir” and an on-device agent turns it into explicit colour adjustments. Each change is listed with the reason for it and a link to the control, so you can take over by hand. Nothing is uploaded: rendering, the agent and storage all run in your browser.

Open iqbalhussein.github.io/ApricitySource on GitHub
Built with
Rust, WebAssembly, WebGPU, Solid.js, TypeScript
Status
Live

What it does

  • Two stages kept apart: correction (exposure, white balance, log camera profiles), then the grade.
  • Waveform, RGB parade and vectorscope.
  • Lift, gamma and gain wheels, eight-band HSL, curves, split tone, grain and LUTs.
  • Works offline as an installable app, and falls back to the CPU without WebGPU.
