Java to UML

Upload .java files and the app parses them with an ANTLR grammar, works out visibility, abstract members, inheritance and composition, and draws the class diagram. Standard library types like ArrayList and HashMap are left out, so the diagram shows only your code.

Source on GitHub
Built with
Next.js, TypeScript, ANTLR4, Mermaid
Status
Source code

What it does

  • Upload several files at once by dragging them in.
  • Pan and zoom around large diagrams.
  • Export as SVG or as a high-resolution PNG.
