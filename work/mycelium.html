Mycelium

The Network tab lists requests in time order, which makes it hard to see which action set off which chain of API calls. Mycelium captures fetch and XHR traffic, drops static assets, and draws the flow between the browser and each service as a sequence diagram that updates as you use the page.

Source on GitHub
Built with
TypeScript, React, Mermaid, Chrome extension APIs
Status
Source code

What it does

  • Click an arrow in the diagram to see that request's headers and status.
  • Pause the diagram to study a complicated flow without it moving.
  • Updates are batched every 500 ms so the diagram doesn't flicker.
  • Follows the DevTools light or dark theme.
